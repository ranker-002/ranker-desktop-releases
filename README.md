# RANKER Desktop

Installateurs et mises à jour de la bêta publique de RANKER Desktop pour Windows, macOS et Linux.

Le code source est maintenu dans un dépôt privé séparé. Ce dépôt contient uniquement des informations de distribution et des fichiers compilés.

Téléchargements : https://rankerapp.site/download

Les versions `desktop-v*` contiennent les installateurs, signatures et sommes SHA-256. La publication `desktop-beta` contient les manifestes du canal bêta.
